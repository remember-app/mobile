# Глоссарий

Общие названия, чтобы в разговоре про приложение мы имели в виду одни и те же экраны.

## Экраны

| Название | Маршрут | Что это |
|---|---|---|
| Разработка | `/` | Служебный экран: тема, язык, сеть, входы в разделы. |
| Приветствие | `/onboarding/welcome` | Первый экран онбординга: фото на весь экран, слоганы, кнопка входа. |
| Почта | `/onboarding/email` | Ввод адреса почты. |
| Код | `/onboarding/code` | Ввод шестизначного кода из письма. |
| Ник | `/onboarding/username` | Выбор ника. |
| Финал онбординга | поверх «Главной», не отдельный маршрут | Конфетти с ником, затем экран сжимается и открывает «Главную». |
| Главная | `/home` | Список воспоминаний, «Новое воспоминание». |
| Новое воспоминание | `/create` | Название, календарь, контакты, лимит места. |
| Воспоминание | `/project/[id]` | Галерея кадров воспоминания с плотностью 1/3/5/7. |
| Выбор фото | `/project/[id]/pick` | Сетка фото из телефона для добавления в воспоминание. |
| Сведения о воспоминании | `/project/[id]/info` | Круги (люди, место, токены), участники, приглашения. |
| Просмотр кадра | поверх «Воспоминания» или «Выбора фото», не отдельный маршрут | Полноэкранный кадр: листание, щипок, свайп вниз для закрытия. |
| Профиль | `/profile` | Имя, ник, почта, лимиты, язык, контакты, выход. |
| Редактирование профиля | `/profile/edit` | Изменение имени и ника. |
| Контакты | `/contacts` | Свой список контактов и предложенные знакомые. |
| Кит | `/kit` | Витрина базовых компонентов. |

## Договорённость о словах

- В интерфейсе сущность называется **воспоминание**, в коде — `project`. Это одно и то же.
- Экран с фото из телефона в разговоре называем **«Выбор фото»**, а не «загрузка»: загрузка — это уже процесс после выбора.
