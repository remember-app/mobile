# Глоссарий

Общие названия, чтобы в разговоре про приложение мы имели в виду одни и те же экраны.

## Экраны

| Название | Маршрут | Что это |
|---|---|---|
| Разработка | `/` | Служебный экран: тема, язык, сеть, входы в разделы. |
| Онбординг | `/onboarding/welcome` | Один экран с тремя ступеньками: фото на весь экран, кнопки входа, затем фото сжимается к центру и появляется блок ввода. |
| Приглашение по ссылке | `/invite` | Открывается по `remember://invite?token=…`: запоминает код и ведёт на онбординг. |
| Главная | `/home` | Список воспоминаний, «Новое воспоминание». |
| Новое воспоминание | `/create` | Название, календарь, контакты, лимит места. |
| Воспоминание | `/project/[id]` | Галерея кадров воспоминания, сетка в три колонки, новые снизу. |
| Выбор фото | `/project/[id]/pick` | Сетка фото из телефона для добавления в воспоминание. |
| Сведения о воспоминании | `/project/[id]/info` | Круги (люди, хранилище, токены), участники, приглашения, лейблы. |
| Просмотр кадра | поверх «Воспоминания» или «Выбора фото», не отдельный маршрут | Полноэкранный кадр: листание, лента-скраббер, видео, свайп вниз для закрытия. |
| Профиль | `/profile` | Имя, ник, почта, лимиты, язык, контакты, выход. Изменение имени и ника — попап на этом экране. |
| Контакты | `/contacts` | Свой список контактов и предложенные знакомые. |
| Кит | `/kit` | Витрина базовых компонентов. |

## Договорённость о словах

- В интерфейсе сущность называется **воспоминание**, в коде — `project`. Это одно и то же.
- Экран с фото из телефона в разговоре называем **«Выбор фото»**, а не «загрузка»: загрузка — это уже процесс после выбора.
